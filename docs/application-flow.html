Guards around the flow

🔒 Safe scraping

  • Public http(s) URLs only: no localhost or private networks
  • Connects to the validated IP (stops DNS rebinding)
  • TLS checked against the real hostname
  • Every redirect hop re-checked (max 5)
  • Text content types only, 2 MB download cap

🔁 Reliability

  • Retries rate limits (413/429) and connection errors, up to 5 attempts
  • Waits are shown in the UI as a notice
  • Tool failures return readable messages instead of crashing a run
  • Errors map to hints: rate limit, bad key, missing setting

🧪 Quality & observability

  • Structured logging with tracebacks on errors
  • 58 offline tests, about 98% coverage (gate: 85%)
  • Lint, tests and dependency audit on every push (CI)
  • Secrets only in git-ignored src/.env
